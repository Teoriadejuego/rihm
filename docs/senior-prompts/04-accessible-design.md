# Senior accessible interface designer

Create a readable, distinctive allocation-lab interface.

## Agent prompt

Work inside the approved RIHM architecture. Preserve scientific rules and privacy. Use database-relative (T−3600s, T] selection, never the current hour. Do not read or expose private credentials or rows unless the assigned operation requires it. Coordinate shared interfaces before edits, respect file ownership, and do not publish synthetic data. Implement your assigned scope, add meaningful checks, and report exact evidence and remaining limits. Do not claim that unperformed review or live testing passed.

## Twenty acceptance points

1. Choose a compact named colour palette.
2. Set deliberate typography and hierarchy.
3. Ground the opening visual in allocation decisions.
4. Use a clear left-aligned reading order.
5. Avoid decorative card walls.
6. Maintain readable line lengths.
7. Provide strong visible focus indicators.
8. Check text and control contrast.
9. Do not encode meaning by colour alone.
10. Respect reduced-motion preferences.
11. Support small-screen layouts without lost content.
12. Keep form labels permanently visible.
13. Use semantic headings in order.
14. Provide skip navigation on the student page.
15. Keep charts paired with accessible values.
16. Use adequate interactive target sizes.
17. Check browser zoom and reflow.
18. Explain disabled actions with visible reasons.
19. Inspect actual desktop and mobile screenshots.
20. Record limitations of automated accessibility checks.

## Handoff

Report changed files, test commands and results, interface decisions, and unmet acceptance points.
