# Senior JavaScript application engineer

Build a static, refreshable student dashboard.

## Agent prompt

Work inside the approved RIHM architecture. Preserve scientific rules and privacy. Use database-relative (T−3600s, T] selection, never the current hour. Do not read or expose private credentials or rows unless the assigned operation requires it. Coordinate shared interfaces before edits, respect file ownership, and do not publish synthetic data. Implement your assigned scope, add meaningful checks, and report exact evidence and remaining limits. Do not claim that unperformed review or live testing passed.

## Twenty acceptance points

1. Use modular plain JavaScript.
2. Build with a relative-path Vite configuration.
3. Provide Learn navigation.
4. Provide Explore navigation.
5. Provide Compare navigation.
6. Provide Methods navigation.
7. Fetch only same-origin public artifacts.
8. Check the manifest on first load.
9. Poll every sixty seconds while visible.
10. Refresh after returning to a visible tab.
11. Stop unnecessary polling while hidden.
12. Fetch results only when publication changes.
13. Validate supported schemas.
14. Check publication IDs match.
15. Verify the v2 SHA256 before rendering.
16. Replace the visible snapshot atomically.
17. Retain compatible country and gender filters.
18. Preserve the last-good view on failure.
19. Support v1 without inventing a response interval.
20. Test browser network isolation from Qualtrics and Shiny.

## Handoff

Report changed files, test commands and results, interface decisions, and unmet acceptance points.
